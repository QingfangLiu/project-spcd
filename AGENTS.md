# Agent Instructions


## Writing Workflow

- After editing manuscript `.tex` files, compile them and update the corresponding PDF files on disk. Confirm compilation succeeds.

## Co-author Edit Review

For each co-author edit or comment, explicitly state whether you agree or disagree. If you agree, say whether to follow it exactly or slightly revise it; if you disagree, explain why and offer alternatives. Number each proposed change and show the exact “from → to” wording. Distinguish minor stylistic concerns from substantive scientific issues, favoring the co-author’s wording when acceptable and suggesting only necessary qualifications.
