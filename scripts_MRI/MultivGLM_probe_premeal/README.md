# SPCD Pre-meal Probe Event & GLM 

---

## 1. Pre-meal Probe Event File Generator

### Purpose
Converts trial-level behavioral CSV files into BIDS-like `events.tsv` files for each subject and run.

### Inputs
- `pre_meal_dat.csv` in `project-SPCD/beh_processed_subs/<subID>/`  
  Must contain:
  - `Run`
  - `trial`
  - `ISIDur`, `ITIDur`
  - `resp`, `rt`
  - `cue_left_idx`, `cue_right_idx`
  - `odor_left`, `odor_right`
  - `set`

### Outputs
- `sub-XX_task-premeal_run-<r>_events.tsv` in `SPCD_data/nii/<subID>/func_PAID/premeal/`

### Columns
- `onset` — event onset in seconds  
- `duration` — event duration in seconds  
- `trial_type` — one of `cue_img1`, `cue_img2`, `decision`, `button`  
- `run` — run number  
- `trial` — behavioral trial number  
- `img_index` — 1 for first cue, 2 for second cue  
- `response_time` — RT for button presses, `NaN` otherwise  
- `response_hand` — `left`, `right`, or `n/a`  
- **`cue_index`** — cue identity index:
  - `cue_img1`: from `cue_left_idx`
  - `cue_img2`: from `cue_right_idx`
- **`odor_index`** — odor identity index:
  - `cue_img1`: from `odor_left`
  - `cue_img2`: from `odor_right`
- **`set`** — trial’s set number (copied from behavior)

### Logic
- Non-cue events (`decision`, `button`) have `NaN` for `cue_index`, `odor_index`, and `set`.
- Pre-run blank = 10 s; cue1 duration = 3 s; ISI = trial-specific `ISIDur`; cue2 duration = 3 s; decision = 2 s; ITI = trial-specific `ITIDur`.

## 2. GLM Beta Index Logger

### Purpose
Links each single-trial beta image from the trial-wise GLM to its source event information.

### Inputs
- `events.tsv` files generated by the event generator
- Beta images generated by the GLM

### Outputs
- `<SubID>_premeal_run-<r>_beta_index.csv` in subject’s GLM beta directory
- GLM beta logs are saved **per run**.

### Columns
- `beta_file` — beta image filename
- `run` — run number
- `event_index` — index within run’s cue events
- `trial` — behavioral trial number
- `img_index` — 1 for first cue, 2 for second cue
- `onset` — onset time of the cue
- `trial_type` — `'cue_img1'` or `'cue_img2'`
- **`cue_index`**, **`odor_index`**, **`set`** — copied from events.tsv

### Logic
- For `cue_img1` betas:
  - `cue_index` = `cue_left_idx`
  - `odor_index` = `odor_left`
- For `cue_img2` betas:
  - `cue_index` = `cue_right_idx`
  - `odor_index` = `odor_right`
- `set` is always copied from the trial’s row.

## 3. GLM Design (conditions)

**Goal:**  
Estimate a separate beta for each cue presentation (Least-Squares-All design).

### Conditions per run
For each cue event _k_:
- **Regressor of interest**
  - `target_cue_k` — 3 s boxcar at onset of the specific cue (either `cue_img1` or `cue_img2`)
- **Nuisance/task regressors**
  - `other_cues` — 3 s boxcar; all cue events except k
  - `decision_all` — 2 s boxcar; all decision events
  - `button_all` — stick (0 s); all button presses
- **Nuisance regressors from file**
  - Motion parameters / physio / other columns from run’s nuisance regressor file
- **Run constants & filtering**
  - SPM run constant
  - High-pass filter (default in SPM for fMRI)

### HRF & masking
- Canonical HRF
- threshold = **0.1**

### Betas saved
- One beta image per `target_cue_k`
- Filename format: `beta_run%02d_img%03d.nii`
